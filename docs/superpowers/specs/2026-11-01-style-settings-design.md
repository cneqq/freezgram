# Стиль Freezgram: единый список

Пользователь выбрал интерактивный макет «Единый список» и поручил попробовать его в приложении. Область — наши редакторы и входы в них, без переделки всего унаследованного «Оформления». Дополнительное требование: предпросмотры показывают реальные компоненты/существующее поведение, без декоративных имитаций из макета.

Единственный вход «Стиль Freezgram» открывает нативный список с группами «Интерфейс», «Чат», «Эффекты». В интерфейсе: навигация, шапка чата, поле ввода и список чатов/папки. В чате: сообщения, подарки, меню/кнопки и вложения. В эффектах: общее стекло, разделители, переходы, снег. Дополнительные строки сохраняют доступ к ранее существующим переключателям; они не добавляют новые эффекты.

Редакторы используют одинаковые тематические секции, строки настроек и компактные ползунки. Общие оптические параметры отделены от выбора поверхностей. Сложные параметры стекла раскрываются через «Дополнительно». Ключи, значения и резервное копирование не меняются. Неприменимые настройки скрываются до выбора соответствующего стиля. Возврат в список обновляет подписи текущих значений.

Альтернатива «По разделам» с вкладками отклонена пользователем в пользу видимого целиком списка. Пресеты и новые эффекты не добавляются. Реальные предпросмотры сообщений/подарков, компоненты навигации и существующая геометрия превью сохраняются. Для новой шапки допускается только реальный ActionBar/ChatAvatarContainer; отсутствие достоверного превью не маскируется рисунком.

Рабочая ветка — no-plugins. Последующим явным указанием пользователь установил постоянный порядок: проверки, коммит, push и APK-сборка; исключение — прямое «без билда». Установка на устройство не запрошена. Проверки: маршруты всех строк, отсутствие записи при открытии списка, существующие регрессии, синтаксис Java и ресурсы. Внешний вид на устройстве проверяется отдельно.
